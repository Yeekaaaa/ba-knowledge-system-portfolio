# Privacy, Copyright, and Sanitisation

## Public disclaimer

**This repository contains educational summaries and portfolio samples, not full proprietary source materials.**

It demonstrates knowledge-system design. It is not a mirror of any private vault.

## Privacy rules

1. **No personal career files** — resume, work authorisation, interview prep, salary expectations, employer application tracking.
2. **No real private projects** — family business systems, unpublished internship work, client identifiers.
3. **No PII** — personal phone, email, address, or identity documents.
4. **No private screenshots** — internal dashboards, Slack, email.

## Copyright rules

1. **Job descriptions** — paraphrased market signals only; no full JD text from commercial platforms unless explicitly permitted.
2. **Articles** — metadata and original paraphrase; no full McKinsey / media article copy.
3. **Papers** — citation metadata and summary; **no Elsevier or paywalled PDF** redistribution in this repo.
4. **Licence unknown** — treat as metadata + summary only.
5. **Code and templates in this repo** — MIT licensed (see [LICENSE](../LICENSE)).

## Sanitisation checklist (before git push)

- [ ] Grep for private project codenames and remove
- [ ] Grep for full JD paragraphs (>100 words from single employer ad)
- [ ] Confirm no `raw/` or private vault paths copied
- [ ] Confirm no `.pdf` from publishers in tree
- [ ] Confirm synthetic files labelled
- [ ] README disclaimer present
- [ ] Third-party URLs cited, not content reproduced

## Fair use / educational framing

Paraphrased summaries of public career guides and research implications are included to demonstrate BA synthesis skill. Rights holders retain copyright in original works. Users should consult original sources via DOI/URL.

## If you fork this repo

- Replace synthetic examples with your own fictional scenarios, or
- Keep a **private vault** for real portfolio evidence and ingest only sanitised extracts here.
