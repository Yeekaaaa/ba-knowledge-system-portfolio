# Prompt: Query Wiki

Use [AGENTS.md](../AGENTS.md).

Answer this question using the sample wiki as the primary source:

`<your question>`

## Steps

1. Read `sample-wiki/index.md`.
2. Open the most relevant whole pages.
3. Synthesise; separate facts from interpretation.
4. Link evidence with `[[page-name]]`.
5. Note gaps where the wiki is incomplete.

## Hard rules

- Do not fabricate personal experience or private project details.
- Do not import content from private vaults.
- If the answer is reusable, propose a wiki write-back location.
